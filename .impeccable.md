## Design Context

### Users
Personal use, possibly shared with wife/family/friends. Opened as a new-tab page — context is quick capture and at-a-glance task review. May be opened at any hour, including late at night.

### Brand Personality
Clear, focused, peaceful. A calm tool that respects your attention and doesn't overstimulate. More "quiet instrument" than "productivity app."

### Aesthetic Direction
- **Dark mode only** — prioritize low blue-light emission for late-night use. Warm, muted tones.
- Minimal, unhurried. The interface should feel like a clean desk, not a command center.
- Anti-references: loud productivity apps, gamified task managers, anything that creates anxiety about getting things done.
- Name: **Jot** — quick, light, personal. Like jotting something down.

### Design Principles
1. **Respect the hour** — dark, warm, low-stimulus. No bright accents that jar at 2am.
2. **Disappear when not needed** — chrome should fade; the task list is the interface.
3. **Instant capture** — typing a task should feel frictionless, like thinking out loud.
4. **Calm clarity** — hierarchy through spacing and weight, not color or decoration.
5. **Personal, not corporate** — this is a home tool, not a SaaS dashboard.
